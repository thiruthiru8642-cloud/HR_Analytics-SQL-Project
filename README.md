# HR Analytics SQL Project

## Project Overview
This project analyzes employee data using MySQL to identify employee attrition patterns and understand workforce trends.

## Dataset
- Total employee records: 1,470
- Total columns: 35
- Dataset: IBM HR Analytics Employee Attrition

## Tools Used
- MySQL 8.0
- MySQL Workbench
- SQL
- GitHub

## Business Questions
1. What is the total number of employees?
2. How many employees left the company?
3. What is the overall attrition rate?
4. Which departments have the highest attrition?
5. Which job roles have the highest attrition?
6. Does overtime relate to employee attrition?
7. What is the average salary by department?
8. How does job satisfaction relate to attrition?
9. How does employee experience relate to attrition?
10. Which age groups have the highest attrition?

## Key Results
- Total employees: 1,470
- Employees left: 237
- Employees stayed: 1,233
- Overall attrition rate: 16.12%
- Average monthly salary: 6,502.93
- Average years at company: 7.01

## SQL Skills
- SELECT, WHERE, GROUP BY, ORDER BY
- COUNT, SUM, AVG
- CASE WHEN
- ROUND
- Data aggregation and analysis

## Conclusion
This project demonstrates how SQL can be used to analyze HR data, identify employee attrition patterns, and generate business insights.
